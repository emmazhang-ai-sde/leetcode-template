Problem

Rearrange the characters of inputStr according to the following algorithm:

  1. Begin with an empty string output = "".
  2. If inputStr does not contain any Ws, go to step 3. Otherwise remove one W from inputStr, append it to output, then go to step 3.
  3. Same as step 2, but for D, then go to step 4.
  4. Same as step 2, but for L, then go to step 5.
  5. If inputStr is empty, stop. Otherwise go back to step 2.

Return output once the algorithm finishes.

Note: a solution up to O(inputStr.length^2) fits the time limit — no need to over-optimize.

Example

For inputStr = "LDWDL", solution(inputStr) = "WDLDL".
