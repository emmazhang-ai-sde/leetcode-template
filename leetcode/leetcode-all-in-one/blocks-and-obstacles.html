Problem

An infinite integer number line supports two kinds of operations:

  • [1, x]: place an obstacle at coordinate x. It is guaranteed that no obstacle is already located there.
  • [2, x, size]: determine whether a block of length size can occupy the integer coordinates immediately before x — the checked interval is [x - size, x - 1].

For each type-2 operation append "1" if the interval contains no obstacle, otherwise "0". Queries only check availability and do not actually add a block. Return the results of all type-2 operations as one binary string.

Example

operations = [[1, 2], [1, 5], [2, 5, 2], [2, 6, 3], [2, 2, 1], [2, 3, 2]]

QueryChecked intervalResult
[2,5,2][3,4] contains no obstacle1
[2,6,3][3,5] contains obstacle 50
[2,2,1][1,1] contains no obstacle1
[2,3,2][1,2] contains obstacle 20

Output: "1010".
