Problem

Given a string s consisting of lowercase English letters, reverse its letters in adjacent pairs:

  • Swap the 1st and 2nd characters.
  • Swap the 3rd and 4th characters.
  • Continue in the same way for the rest of the string.
  • If the string has an odd number of characters, leave the final character unchanged.

Examples

s = "abcdef" → "badcfe"

s = "abcde" → "badce"（奇数长度,最后的 e 不动）
