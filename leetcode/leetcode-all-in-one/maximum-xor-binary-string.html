x XOR y — 要最大化的结果

Problem

You are given bits, maxSet, and x, where:

  • bits is the length of the binary string.
  • x is a binary string of length bits.
  • maxSet is the maximum number of bits that may be set to '1' in another binary string y.

Construct a binary string y of the same length such that x XOR y is maximized.

The string y must satisfy:

  • The number of '1' bits in y is at most maxSet.
  • Leading zeros are allowed.

Return the binary string y that produces the maximum XOR value.

Example

For bits = 3, x = "101", maxSet = 1:

  • Possible y with at most one '1': 000 / 001 / 010 / 100
  • XOR values: 101 / 100 / 111 / 001
  • The maximum is 111, so y = "010".

Key observation: x[i] == '1' 的位永远填 y[i] = '0'（XOR 已经是 1）；x[i] == '0' 的位填 '1' 才能把 XOR 变成 1——但 '1' 的配额只有 maxSet 个。高位数值最大，所以把配额从左往右贪心地花在 x[i] == '0' 的位置上，一趟扫完。
