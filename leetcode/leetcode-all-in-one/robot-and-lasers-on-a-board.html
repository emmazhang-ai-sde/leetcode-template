Problem

There is a numRows × numColumns board. Each laser is located at [row, column] and destroys every cell in its entire row and entire column.

A robot initially stands at (curRow, curColumn). Its initial cell is protected, even if a laser covers that cell. The robot chooses one of four directions — up, down, left, or right — and then moves only in a straight line without turning.

Return the maximum number of safe cells the robot can move through before reaching a laser-covered cell or leaving the board. Coordinates are 1-based.

Example

numRows = 8, numColumns = 8, curRow = 5, curColumn = 3, laserCoordinates = [[1, 6], [2, 8]]

Dangerous rows {1, 2}, dangerous columns {6, 8}:

DirectionSafe cellsCount
Up(4,3), (3,3)2
Down(6,3), (7,3), (8,3)3
Left(5,2), (5,1)2
Right(5,4), (5,5)2

Output: 3.
