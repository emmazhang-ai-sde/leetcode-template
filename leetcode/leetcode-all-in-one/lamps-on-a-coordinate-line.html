Problem

Lamps sit on a coordinate line, each illuminating a range around itself. You're given a 2-D array lamps, where lamps[i][0] is the ith lamp's coordinate and lamps[i][1] is its (positive) radius — so it lights every integer coordinate from lamps[i][0] - lamps[i][1] to lamps[i][0] + lamps[i][1] inclusive.

Find the number of integer coordinates illuminated by exactly 1 lamp.

Example

For lamps = [[-2, 3], [2, 3], [2, 1]], solution(lamps) = 6.

  • [-2 - 3, -2 + 3] = [-5, 1]
  • [2 - 3, 2 + 3] = [-1, 5]
  • [2 - 1, 2 + 1] = [1, 3]

Coordinates lit by exactly 1 lamp: [-5, -4, -3, -2, 4, 5] → output 6.
