breakpoints（有序断点表）

actions（依次处理）

移动轨迹 Movement

TikTok OA · 2026-08-16 · no official LeetCode number

Problem

You are debugging a code snippet whose final line number is codeLength. The sorted list breakpoints contains unique breakpoint line numbers. The debugger initially starts on line 1.

Process every string in actions:

  • "next": move forward exactly one line.
  • "continue": move forward to the first breakpoint strictly after the current line.

Return the line on which the debugger finishes. The input guarantees that every action is valid.

Example

codeLength = 55, breakpoints = [2, 5, 21, 44], actions = ["next", "next", "continue", "next", "next"]

Movement: 1 → 2 → 3 → 5 → 6 → 7 → output 7.
