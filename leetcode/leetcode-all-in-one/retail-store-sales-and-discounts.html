Problem

Implement a simplified inventory tracker for a retail store. You're given a price list priceList (current price per item) and a chronological transaction log logs containing sell, discount_start, and discount_end records. Process all transactions and return the total revenue.

Each price list entry has the form "<item_name>: <price>".

Transaction formats

  • "sell <item_name>, <count>" — sell <count> units of <item_name>.
  • "discount_start <item_name>, <discount_amount>, <max_count>" — start selling <item_name> at price - <discount_amount>, for at most <max_count> units (≤ 100); extra units sell at the original price. Only one discount per item at a time.
  • "discount_end <item_name>" — end the discount for <item_name> (guaranteed to have an active discount at that point).

Note: transactions arrive already sorted chronologically; a solution up to O(logs.length^2 · priceList.length) fits the time limit.
