Breadth First Search / Depth First Search

BFS
DFS
Core idea
Expands outward layer by layer: first to arrive is shortest / optimal
Follows one path to the end, backtracks to try another when stuck
Data structure
Queue (deque) + level batching: snapshot size = len(queue), finish one level before the next
Recursive call stack, no explicit queue
Visited set?
Yes, added but never removed: first arrival is already shortest, no need to revisit
Yes, added then removed (backtrack), undone on the way back so other paths can reuse the state
Special case
Dijkstra: swaps the queue for a heap (heapq), greedily pops by distance instead of by level
Tree: divide-and-conquer, no visited / backtracking needed, merges results from subtree return values
What it collects / returns
Step count, reachability, shortest distance
Merged subtree result, or all paths / all combinations (enumeration-style)
